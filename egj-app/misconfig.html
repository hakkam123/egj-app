⚠️ Konfigurasi IIS Salah

IIS site menunjuk ke folder root project, bukan ke folder public/.

Ini masalah keamanan — file .env dan source code bisa terbaca user kalau tidak diperbaiki.

Perbaikan:
  1. Buka IIS Manager
  2. Pilih site JAGO
  3. Klik Basic Settings → ubah Physical Path dari:
    C:\...\jago\egj-app
    menjadi:
    C:\...\jago\egj-app\public
  4. Klik OK, lalu jalankan iisreset di PowerShell admin

Kalau Anda user biasa yang melihat halaman ini, hubungi tim IT dan tunjukkan pesan ini.
